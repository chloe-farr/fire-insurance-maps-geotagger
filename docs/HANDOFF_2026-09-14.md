# Handoff notes — 2026-09-14

Written at the end of a long working day so the state is clear tomorrow. Everything below is in git (see `git log`).
The pipeline is entirely local: HunyuanOCR (open weights, this machine's GPU), Surya, OpenCV, numpy. No hosted model,
no API key, no agent is called anywhere. The only network access is `fim_fetch_streets.py`, which downloads a public
street-centreline layer once per area (OpenStreetMap or a municipal ArcGIS service; a layer you already have works too),
and — added 2026-09-16 — `fim_locate.py`, which asks Nominatim (OpenStreetMap's place index) where a sheet's street
names co-occur when nobody knows what city a sheet shows.

## What runs, in order (one sheet)

```bash
# 1. words with pixel coordinates (GPU, ~9 min for a dense 100 ft/in sheet, ~13 min for a key plan with 3 views)
python3 scripts/fim_tile_ocr.py data/1895/p25.jpg --crop 250,120,7110,8040 --tile 1024 --rotations 0 --max-new-tokens 4096 -o runs/hunyuan/<date>_tiles_p25_t1024
#    key plans / sheets with text at many angles: --rotations 0,30,60
# 2a. outlined blocks (detailed sheets)              -> <run>/<stem>_blocks_px.geojson  (+ _blocks.csv, _blocks_overlay.jpg)
python3 scripts/fim_blocks.py runs/hunyuan/<run>
# 2b. colour-washed areas (key plans; YOU decide to run this — nothing auto-detects tints)
python3 scripts/fim_areas.py  runs/hunyuan/<run>                 -> <run>/<stem>_areas_px.geojson (+ _areas.csv, _areas_overlay.jpg)
# 3. modern street layer, once per city (any bbox / place; OSM or --arcgis <layer url>)
python3 scripts/fim_fetch_streets.py --bbox 48.40,-123.46,48.475,-123.30 --slug capital_region_crd --epsg 26910 \
    --arcgis https://mapservices.crd.bc.ca/arcgis/rest/services/Roads/MapServer/14
# 4. georeference from the OCR'd street names; places blocks, areas, tokens, page footprint; cleans block/area attributes
python3 scripts/fim_georef.py runs/hunyuan/<run> --streets data/modern/capital_region_crd_streets_epsg26910.geojson \
    --alias configs/georef/aliases_victoria_1895.json
# 5. the interactive viewer (self-contained HTML, no network)
python3 scripts/fim_viewer.py runs/hunyuan/<run1> runs/hunyuan/<run2> ... -o docs/viewer.html --title "..." --default p03
```

Per-sheet decisions still made by a person (everything else is the same command for every sheet):
- the crop box (`--crop`) that keeps the margin, colour bar and ruler out — four numbers read off a thumbnail;
- OCR tile size / views / cap: 1024 px tiles + 4096 cap for dense sheets; add `--rotations 0,30,60` when text runs at
  many angles (key plans, diagonal streets). 1536 px tiles at an 8192 cap hit the cap on 16/27 views of p25;
- whether the sheet is tinted (run `fim_areas.py`) — explicit by design, per Chloe's request;
- which modern layer: the City of Victoria layer for sheets inside the city, the CRD regional layer (or OSM) when a
  sheet reaches into Esquimalt / Saanich. Any box works — the layer is never clipped to a municipality — and a sheet of
  unknown location gets a proposed box from `fim_locate.py` (2026-09-16), which the person accepts by candidate number.
Everything else — scale, rotation, skew, translation, outlier rejection, street matching, block cleaning — is solved
by the scripts from the data. Nothing is hand-placed.

## What changed today (all in scripts/, documented in README.md)

- **fim_georef.py** — city-agnostic (any named-centreline layer, any UTM zone natively, other CRSs via pyproj);
  intersections derived from the centrelines; scale seeds from the sheet's own "Scale N feet = 1 inch" statement
  (ranked so a key plan's quoted scales for other sheets, or an inset's, do not win) *added to* a wide default list;
  candidate radius, search grid and outlier floor all scale with the sheet (`--outlier-px 60`: ~3 m on a 50 ft/in
  sheet, ~30 m on a 500 ft/in key plan); iterative outlier rejection; direction suffixes ("Burnside Rd E") handled;
  blocks cleaned (real street labels only, modern bounding streets with side, frames/buildings/compounds rejected,
  compounds cut along modern centrelines, street-widening slivers dropped); page footprint; areas pass.
- **fim_areas.py** (new) — colour-wash areas: paper colour → chroma offset → tints by k-means in Lab a/b (a "blue" wash
  on cream is just less yellow than the paper; HSV saturation is useless for it) → per tint, merge across street lines,
  fill, trace → drop stains (touch the border, no numerals) and the water tint (thin, no numerals) → number = the big
  upright numeral inside (≥1.9× the median numeral height); an area holding two big numerals is split between them.
- **fim_fetch_streets.py** (new) — OSM (Overpass, mirrors tried in order; `maps.mail.ru` and `overpass-api.de` worked
  today) or any ArcGIS layer, paged; auto UTM zone. `fim_crs.py` (new) — UTM forward/inverse without pyproj.
- **fim_viewer.py** (new) + `configs/viewer/template.html` — the interactive page (tabs per sheet, blocks, tinted areas,
  every word, residual table, block table). Built locally as `docs/viewer.html` (not tracked; the earlier published
  copy was taken down 2026-09-15 — rebuild with the command above).
- **fim_blocks.py** — writes `<stem>_blocks_px.geojson` (pixel space; the `_px` says it is not a map).
- `data/modern/`: City of Victoria Streets (whole city), CRD regional roads (layer 14), OSM for the region and the
  city. `data/gcp/`: the 1884 `.points` file (unusable — metres not pixels; documented).

## Known limits / next steps (in rough priority)

1. **Outlined-block recovery is incomplete** on dense sheets (p25: 204–207, 210–213, 216 missing): dashed or open
   outlines. Best idea: after georeferencing, use the modern centrelines (buffered by street width) to partition the
   content box; intersect with the ink evidence. Same trick as the compound splitter, applied sheet-wide.
2. **Big-numeral misreads** on key plans (`431` for 31, `129` for 11, `800`) come from HunyuanOCR; a second read of
   just those crops (upright, high-res) would fix most. Numbers carry `number_is_big_numeral` so they can be audited.
3. **OCR speed**: serve HunyuanOCR through vLLM (batched tiles), keep 1024 px tiles + 4096 cap, rotated views only where
   Surya finds tilted lines, abort runaway repetition. Today: ~9 min/dense sheet upright, ~13 min/key plan with 3 views.
4. **Auto-crop**: detect the paper vs the black scanner margin, colour bar and ruler, so `--crop` goes away.
5. **Mosaic**: sheets are fitted independently (2–13 m RMS each); a joint fit sharing streets across sheet edges would
   make the book seamless.
6. **Aliases**: `configs/georef/aliases_victoria_1895.json` holds only Bastion/Commercial so far. p25 names with no
   modern match (Frederick, Putnam, Alfred, Elizabeth, St. Louis, Cadboro Bay Rd) would join the fit if their modern
   names were added — the compound split already showed St. Louis + Elizabeth = today's Mason St.
7. p02 fit is the loosest (12.8 m): Esquimalt streets were re-aligned; also many legend words matched street names
   (FIRE → Fire Lane, STORE → Store St) and were rejected as outliers correctly but noisily.
